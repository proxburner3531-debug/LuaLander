# Lua Lander

A lunar-lander-style game developed with Unity and C# while learning game development.

## Overview

Lua Lander is a space-themed landing game in which the player controls a lander and attempts to land safely on a landing pad.

This project was developed as a hands-on learning exercise using Unity, C#, and tutorials from Code Monkey.

## Features

- Main menu with Play and Quit options
- Lander movement and thrust controls
- Fuel-based gameplay
- Landing-pad interaction
- Space-themed visual environment
- Joystick support

## Technologies Used

- Unity
- C#
- Visual Studio
- Unity Input System 

## Getting Started

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add project from disk** and choose the cloned `LuaLander` folder.
4. Open the project with a compatible Unity version.
5. Open the main menu scene and press Play.

## Controls

| Action | Control |
|---|---|
| Move left | A / left arrow key / joystick |
| Move right | D / right arrow key / joystick |
| Apply thrust | W / up arrow key / joystick |
| Pause or return to menu | click the respective buttons |
